# 🍳 CookBook — Recipe API Website

CookBook is a beginner-friendly recipe website built using **HTML, CSS, and JavaScript**. It uses the **DummyJSON Recipes API** to fetch and display recipe data dynamically.

The project focuses on practicing **JavaScript API integration, Fetch API, DOM manipulation, search functionality, and interactive UI elements**.

## ✨ Features

* 🍽️ Display recipes dynamically using an API
* 🔍 Search recipes by name
* ❤️ Add recipes to Favourites
* 📋 View detailed recipe information
* ⭐ Display recipe ratings
* 🌎 Show cuisine and difficulty
* ⏱️ Display preparation and cooking time
* 👥 Display servings information
* 🖼️ Recipe images fetched directly from the API
* 📱 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Functionality and DOM manipulation
* **Fetch API** — Fetching recipe data
* **DummyJSON Recipes API** — Recipe data source

## 🔗 API Used

This project uses the DummyJSON Recipes API to fetch recipe information.

API: https://dummyjson.com/recipes

## 🚀 How It Works

1. The website fetches recipe data from the DummyJSON API.
2. JavaScript processes the API response.
3. Recipe cards are dynamically created and displayed on the page.
4. Users can search for recipes using the search bar.
5. Users can open a recipe to view its detailed information.
6. Recipes can be added to the Favourites section.
